## Sprint 2

### Xueyan Zhang

I used Claude as my main AI tool this sprint. I used it to plan and write the skeleton code step by step: the Makefile, the REPL loop, the parser, and the fork/exec code. I also used it to draft the glossary and update the README.

AI helped most by keeping each step small. I compiled and tested every piece before moving on, so I understand each file instead of getting one big block of code. One concrete example is the Makefile. Pasting tabs into my terminal kept breaking, so Claude suggested .RECIPEPREFIX, which I did not know about. It also noticed I first ran my setup check on my Mac instead of the Linux VM.

AI also had limits. Long code blocks pasted over SSH got garbled, and one file came out incomplete, so I had to split it into smaller parts. The parser it gave me only splits on spaces, so ls>out is not detected yet. I also had to double check facts against sources instead of trusting them.
